Quick Integration Example (cURL & REST)

Official endpoint request to create instant automated orders

Interactive API Docs ↗
curl -X POST https://wsstore.pro/api/b2b/orders/create \ -H "Content-Type: application/json" \ -H "X-API-KEY: wn_live_..." \ -d '{ "category_id": "pubg_mobile_auto", "offer_id": "60_uc", "player_id": "5124893721" }'

Request Headers & Payload Parameters:

POST /api/b2b/orders/create — Automated endpoint to create instant game top-ups or voucher orders.
X-API-KEY — Your private authorization token passed via request headers.
category_id — Unique game or service identifier (e.g. pubg_mobile_auto).
offer_id — Specific package or denomination to order (e.g. 60_uc).
player_id — Destination Player ID / Character ID for direct in-game delivery.
