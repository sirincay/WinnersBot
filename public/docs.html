Overview & Base URL

The Winners API is organized around REST. All requests require SSL and accept/return standard JSON payloads.

⚡ Production Base URL: https://wsstore.pro/api/v1

Authentication

Pass your secret API key in the HTTP request header with either X-API-KEY or Bearer authorization: 

// Recommended HTTP Header:
X-API-KEY: wn_live_9f8a3c2b1e4d5f6a7b8c9d0e1f2a3b4c

// Alternative Authorization Header:
Authorization: Bearer wn_live_9f8a3c2b1e4d5f6a7b8c9d0e1f2a3b4c

Account & Balance Details

GET /api/v1/getMe

Returns real-time account status, Telegram identity, active balance in AZN, and API key metrics.

HeaderTypeStatusDescription
X-API-KEY string Required Your secret API token (Format: wn_live_...)

  -H "X-API-KEY: wn_live_YOUR_KEY"

Validate Player ID & Username Lookup

POST /api/v1/validate-player-id

Checks if a player account ID exists and retrieves their official in-game nickname/character name before charging customer balance.

FieldTypeStatusDescription
category_idstringRequiredE.g. pubg_mobile_auto, free_fire_id
player_idstringRequiredIn-game numeric Player ID / User ID
additional_fieldsobjectOptionalExtra fields like zone_id for Mobile Legends
 
curl -X POST "https://wsstore.pro/api/v1/validate-player-id" \
  -H "X-API-KEY: wn_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "category_id": "pubg_mobile_auto",
    "player_id": "5123456789"
  }'
Response 200 OK
{
  "ok": true,
  "username": "★ShadowHunter★"
}

Create Direct ID Top-Up Order

POST /api/v1/orders/topup

Executes instant direct deposit onto a Player ID. Balance is debited atomically upon fulfillment.

FieldTypeStatusDescription
category_idstringRequiredE.g. pubg_mobile_web
offer_idstringRequiredTarget offer ID from /offers
player_idstringRequiredIn-game User ID of recipient
 
curl -X POST "https://wsstore.pro/api/v1/orders/topup" \
  -H "X-API-KEY: wn_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "category_id": "pubg_mobile_web",
    "offer_id": "174",
    "player_id": "5123456789"

Purchase Digital Voucher / E-Pin

POST /api/v1/orders/giftcard

Purchases digital card pins. Returns unmasked codes and activation keys instantly in payload.

FieldTypeStatusDescription
category_idstringRequiredE.g. pubg_mobile_epin
offer_idstringRequiredPackage SKU ID
countintegerOptionalNumber of cards (1 to 20, default: 1)

  -H "X-API-KEY: wn_live_YOUR_KEY" \
  -H "Content-Type: application/json" \

Error Handling & Status Codes

Errors follow RFC standard HTTP status codes accompanied by a descriptive JSON message.

HTTP CodeError IdentifierMeaning
401 UnauthorizedUNAUTHORIZEDMissing, expired or inactive API Key.
400 Bad RequestINSUFFICIENT_FUNDSAccount balance is insufficient for transaction.
400 Bad RequestINVALID_PARAMSMissing required body fields (e.g. player_id).
404 Not FoundNOT_FOUNDSpecified category or offer ID does not exist.
500 Internal ErrorSERVER_ERRORProvider timeout or network latency.
